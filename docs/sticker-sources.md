# 表情包/贴纸素材来源调研

> 2026-10-07 调研。目的：替代成片中纯文字卡片的画面表达，给分镜加「表情包/贴纸」层。
> 结论先行：**采用「用户自备素材 + 引擎合成」模式**——引擎只认 `assets/stickers/` 下的本地图片并做 ffmpeg overlay，不负责素材分发。理由见版权评估。

## 素材来源清单

### A 档：官方表情包（方舟味最正，二创使用是社区通行做法）

| 来源 | 内容 | 获取方式 |
|---|---|---|
| 微信表情商店 | 搜「明日方舟」「终末地」，多套官方专辑（明日方舟第 1/2 弹…、终末地表情包 03/05/07…） | 免费「添加」，无文件下载按钮 |
| QQ 表情商店 | 同上 | 免费「添加」 |
| 官方微博 @明日方舟 | 节日/活动表情包原图九宫格 | 手动长按保存 |

**从微信提取文件**（引擎需要本地文件）：

- PC 端微信缓存中的表情文件**无后缀名**，实为 PNG/GIF，改后缀即可用
- 批量导出工具：
  - [wechat-sticker-extractor](https://github.com/daodaolee/wechat-sticker-extractor)（开源，自动定位微信数据目录，导出 PNG）
  - 「微信表情包吸血鬼」（图形界面，粘贴数据目录一键导出）
- 手机端：静态表情可长按「保存图片」；GIF 需走 PC 端
- 微信上传表情包的官方规格是 240×240 PNG，导出的原图偏小——**放 1080p 成片要按 2-3x 放大或只作角标使用**，这是画质上最大的现实限制

### B 档：游戏内官方素材（经 PRTS wiki 转载）

- 可用类型：干员头像、立绘、Q 版小人（spine 首帧截图）、道具/技能图标、敌人头像——做「贴纸」效果最实用的是**头像 + 图标**，天然方形、透明底多
- PRTS 走 MediaWiki 标准 API（`Special:FilePath` / `action=query&titles=File:…&prop=imageinfo&iiprop=url`）可按文件名拉原图，未来可给 `corpus-cli` 加 `asset` 子命令
- 版权：素材本身归鹰角网络所有，PRTS 只是转载展示，PRTS 的 CC 许可**不**覆盖这些图

### C 档：版权干净通用 emoji（零风险兜底，可随 zip 分发）

| 项目 | 许可证 | 商用 | 署名 | Copyleft |
|---|---|---|---|---|
| [Twemoji](https://github.com/jdecked/twemoji) | CC BY 4.0 | ✅ | 需要 | 无 → **首选** |
| [OpenMoji](https://openmoji.org) | CC BY-SA 4.0 | ✅ | 需要 | 衍生物需同许可 |
| [Fluent Emoji](https://github.com/microsoft/fluentui-emoji) | MIT | ✅ | 无强制 | 无 |
| Noto Emoji | Apache 2.0 / OFL | ✅ | 保留声明 | 无 |

C 档不是方舟味「表情」，但作为情绪符号/强调符号完全干净，甚至可以直接打进 portable zip（保留 LICENSE 文件）。

## 版权评估

1. **鹰角没有公开的「明日方舟二创规范」独立页面**（对比米哈游、卡普空都有成文指南）。可依据的只有：[鹰角用户协议](https://user.hypergryph.com)、官方表情包「免费添加」的授权暗示、B 站二创生态的普遍惯例。
2. 官方客服确认表情包免费添加使用：[如何在微信/QQ平台下载使用明日方舟表情包](https://customer-service.hypergryph.com/app/arknights/question/ART176758328528154981475431)——但这是指聊天使用，二次创作引用属灰色地带，B 站惯例允许。
3. **PRTS wiki 许可 = CC BY-NC-SA 4.0**（页脚已确认），含**非商业**条款：PRTS 编辑者产出的文字/整理内容，非商业使用需署名 + 相同方式共享；**商用需另行许可**。游戏素材图则与 PRTS 许可无关，一律归鹰角。
4. **商业化是红线**：视频一旦开充电/接商单/带带货，官方素材 + PRTS 内容的引用就从「社区容忍的二创」变成「商业使用」。
5. 通行免责声明写法（视频简介 + 片尾）：「本视频为非官方二次创作，与上海鹰角网络科技有限公司无关；《明日方舟》游戏素材版权归鹰角网络所有」。
6. 不建议引入：NGA 喵舔酱 AC 娘方舟表情（个人作者作品，需单独联系授权）、ChineseBQB 等通用表情仓库（内容版权状况混杂无法溯源）。
